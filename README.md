# Sistema de Gestión Académica

## Descripción

Este proyecto es un sistema de gestión de información académica.
Su finalidad es organizar y gestionar información relacionada con
estudiantes y cursos.

## Objetivo

Desarrollar un sistema sencillo que permita administrar información
académica y aplicar buenas prácticas de control de versiones mediante
Git y GitHub.
